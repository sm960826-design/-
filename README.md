## 1. 저장소 만들기
1. github.com 로그인 → 우측 상단 `+` → **New repository**
2. Repository name: `regulations` (원하는 이름 아무거나)
3. **Public** 선택 (Private은 Pages 무료 제공 대상이 아님)
4. **Create repository**

## 2. 파일 올리기
1. 만든 저장소 화면에서 **Add file → Upload files**
2. 아래 7개 파일을 전부 끌어다 놓기
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - icon-maskable.png
   - apple-touch-icon.png
3. 아래 **Commit changes** 클릭

※ index.html이 10MB라 업로드에 2~3분 걸립니다(GitHub 제한은 파일당 25MB).

## 3. Pages 켜기
1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 새로고침하면 주소가 나옵니다:
   `https://<내아이디>.github.io/regulations/`

## 4. 직원에게 배포
위 주소를 공지하면 됩니다. PC·안드로이드·아이폰 모두 브라우저로 열립니다.

**앱처럼 설치하기**
- 안드로이드(크롬): 접속하면 하단에 설치 안내가 뜹니다. 안 뜨면 우측 상단 ⋮ → 「앱 설치」
- 아이폰(사파리): 하단 공유 버튼 → 「홈 화면에 추가」 (크롬이 아니라 **사파리**로 열어야 합니다)
- PC(크롬/엣지): 주소창 오른쪽 설치 아이콘

설치하면 「재단 규정집」 아이콘이 생기고, 주소창 없이 전체화면으로 뜨며, 한 번 연 뒤에는 **인터넷 없이도** 열립니다.

## 5. 규정이 바뀌었을 때
1. 프로그램에서 규정을 갱신한 뒤 「업데이트 반영해 파일 저장」으로 새 HTML을 받습니다.
2. 받은 파일 이름을 **index.html** 로 바꿉니다.
3. GitHub 저장소 → **Add file → Upload files** 로 덮어씁니다.
4. `sw.js` 파일을 열어 둘째 줄 `const VERSION = 'v20260913-1';` 의 날짜를 바꿔 저장합니다.
   (이걸 바꿔야 이미 설치한 직원 화면이 새 내용으로 갱신됩니다)
5. 직원이 앱을 다시 열면 "규정이 갱신되었습니다 → 새로고침" 안내가 뜹니다.
